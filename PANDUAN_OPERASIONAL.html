PEMERINTAH KELURAHAN MALLILINGI, KECAMATAN BANTAENG, KABUPATEN BANTAENG

Media Instruksional Mandiri Hasil Output Program Kerja Individu KKN 2026

1. Pendahuluan

Dokumen ini berfungsi sebagai panduan acuan mandiri bagi perangkat pemerintah Kelurahan Mallilingi dalam mengoperasikan, memperbarui data berita, syarat pelayanan publik, serta potensi UMKM pada sistem portal web resmi kelurahan.

2. Struktur Sistem

  • Portal Publik (index.html): Tampilan depan informasi warga dan pelayanan online.
  • Admin Media Management (admin.html): Panel visual pengelolaan data khusus perangkat kelurahan.

3. Alur Penggunaan Dashboard Media

Langkah 1: Masuk ke Panel Kelola
Buka file admin.html atau klik tombol 🔐 Pengelolaan Media pada navigasi website.
Masukkan PIN Akses: 1234
Langkah 2: Menambah / Memperbarui Berita & Layanan
Pilih menu tab yang sesuai (Berita / Layanan / UMKM), kemudian klik tombol ➕ Tambah. Isi formulir visual dan simpan. Data pada website publik akan terupdate secara instan.
Langkah 3: Cadangan Data (Backup & Restore)
Pada tab 📦 Cadangan Data, klik Unduh Backup JSON untuk menyimpan file cadangan data kelurahan ke flashdisk atau Google Drive.

4. Serah Terima Sistem

Sistem ini diserahterimakan secara penuh kepada Pihak Pemerintah Kelurahan Mallilingi selaku pemilik sistem untuk dimanfaatkan sebesar-besarnya demi kemajuan pelayanan publik warga Bantaeng.
