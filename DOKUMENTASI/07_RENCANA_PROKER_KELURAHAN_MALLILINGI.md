# Rencana Program Kerja Individu KKN: Website Profile Kelurahan Mallilingi

## 🎯 Deskripsi Proker
Pengembangan **Portal Informasi Publik & Sistem Pengelolaan Media Terpadu Kelurahan Mallilingi** (Kecamatan Bantaeng, Kabupaten Bantaeng, Sulawesi Selatan) untuk mempermudah masyarakat mengakses persyaratan layanan surat kependudukan, berita kelurahan, direktori UMKM lokal, serta profil pemerintahan kelurahan.

---

## 🛠️ Komponen Luaran
1. **Portal Publik (`index.html`)**: Halaman utama portal publik responsif untuk warga.
2. **Dashboard Admin (`admin.html`)**: Sistem pengelolaan data mandiri untuk staf kelurahan (Password PIN `1234`).
3. **Modul Panduan Operasional (`DOKUMENTASI/`)**: Seluruh berkas dokumentasi, petunjuk teknis, dan mekanisme pengajuan subdomain Pemkab.
